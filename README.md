# Predicting Credit Card Default
CAP 5768 – Intro to Data Science, FIU

**Team:** Michele Ballanti, Matteo Piccardo, Raul Alfonso

## Project
Predict which credit card clients will default next month, considering
the cost of errors, model fairness, and client risk profiles.

## Dataset
[Default of Credit Card Clients – UCI](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients)
30,000 clients, Taiwan, 2005. Stored in `data/`.

## Structure
- `data/` – raw dataset
- `notebooks/` – Jupyter notebooks (EDA, models, analysis)
- `src/` – reusable Python functions
- `figures/` – saved plots for report and slides
